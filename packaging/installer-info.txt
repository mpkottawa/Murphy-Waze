Murphy Waze 2.0.00 - Windows x64

Run one installer to install the application and check its dependencies. Missing components and models are downloaded over the internet. This is not an offline bundle.

Allow at least 30 GB free for Python runtimes, VoiceStudio, caches and AI models, plus your recordings. Compatible installed components and verified downloads are reused.

After installation, open Settings / updates. Sign in to ChatGPT through the official Codex browser/console flow and optionally choose a model or a previously configured provider profile. Manual script import is also supported. Murphy Waze does not store account passwords or copy sign-in credentials.

GPU/CPU speech scanning is installed separately from voice generation. Full speaker separation requires signing into Hugging Face and accepting Community-1's conditions; setup reports this as pending when access is not available. Audio generation stays local. Voice approval and uploading remain explicit user steps.

Future .mwupdate files can be imported inside Settings / updates. Voice libraries, backups, credentials and private runtimes are excluded from update payloads. Replaced application files have rollback copies.

Python and media tools are private to the application. Microsoft's C++ runtime may request elevation. VoiceStudio is a separate application. Existing voices are kept when installing over the same directory.

This unsigned installer is an independent community project, not affiliated with Waze, Google, OpenAI or VoiceStudio.
