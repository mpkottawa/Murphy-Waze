# Saved voice reference collection

[Download ZIP](https://github.com/mpkottawa/Murphy-Waze/releases/download/v2.0.00/Murphy-Waze-Voice-References-2.0.00.zip) | [SHA-256](https://github.com/mpkottawa/Murphy-Waze/releases/download/v2.0.00/Murphy-Waze-Voice-References-2.0.00.zip.sha256)

This optional archive contains the latest approved reusable reference from each saved voice folder. The two Randy Marsh names are separate saved variants. Unapproved Ricky material and episode-matcher test data were excluded. Original backups remain untouched.

## Reuse

1. Install Murphy Waze and finish model/account setup as needed.
2. Extract the ZIP to a folder you keep.
3. On My voices, enter the voice name and choose I have a reference / Use my voice reference.
4. Select its reference.wav and use the entire clip, from zero to the duration in voice.json.
5. Create/paste a new script, generate two tests, listen and explicitly approve before generating all 39.

These are reference audio clips, not trained model weights or guaranteed identical recreations. Compatible generation models are still needed. Engine/model/settings changes can change the result. The software license does not grant rights to source performances or character/person identities. Use only where you have the necessary rights and permissions.
